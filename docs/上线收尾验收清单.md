# 上线收尾验收清单

本文记录正式上线前的收尾检查项。每次功能调整后，如影响主管、员工流程或上线规则，需要同步更新本文档和《主管和员工使用说明》。

## 一、全流程验收

当前自动化测试覆盖并已通过：

- 员工提交链上流水批注后进入待审核。
- 主管审核通过后进入正式业务统计。
- 主管驳回后，员工可修改并重新提交。
- 已审核批注可提交修正版本，修正审核通过后新版本生效。
- 已审核批注可提交取消入账版本，取消入账审核通过后不再计入业务收支。
- 非业务流水可由主管标记，并可恢复为待批注。
- 凭证图片仅允许图片类型，支持压缩和权限下载校验。
- 钱包纳入管理起始时间可控制历史流水是否默认需要批注。
- 内部划转两侧流水可识别为一笔业务记录，且不计入进账、出账统计。
- 链上流水排序和待处理状态优先级正常。
- 主管提交租用续费交易哈希后，系统按哈希排重并校验续费。
- 未开通租户按首次开通优惠价付款时，可以自动开通；平台收款钱包可在主管端一键复制。
- 租用金额异常时进入平台收入列表，由管理员人工处理。
- 管理员可按月、按天或月数加天数给租户手工续费。
- 到期租户可自动停用，续费后可自动启用。
- 多租户数据视图隔离正常。
- 员工查看全部账目权限生效。

最近一次完整测试结果：

- 命令：`node --test`
- 结果：`61/61` 通过

## 二、权限和可见性

已覆盖：

- 员工不可审核批注。
- 员工无账号管理、系统管理、服务器管理权限。
- 未勾选查看全部账目时，员工只能看到自己的批注记录和待处理流水。
- 主管只能看到本系统数据。
- 管理员可查看全局数据。
- 主管看不到管理员的查看级操作日志，例如查看凭证、导出、手动查询等。
- 非管理员看不到平台收入列表和线下手工续费入口。

上线前仍建议人工复核：

- 分别用管理员、主管、员工账号登录，确认左侧菜单和页面入口符合预期。
- 用员工账号确认不能进入审核中心、账号管理、租用管理、系统管理、服务器管理。
- 用主管账号确认只能看到本系统钱包、流水、员工和日志。
