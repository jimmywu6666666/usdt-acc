# 正式上线版本说明

本文用于正式上线前后的交付确认和运营维护。它不是主管、员工使用手册，不会作为系统内说明展示给普通业务用户。

生成日期：2026-06-08

## 一、系统定位

项目名称：智慧星 USDT 财务记账系统

当前版本定位为 TRC20 USDT 现金流台账、链上流水批注审核、往来款管理和租用续费管理系统。核心目标是让团队能围绕真实链上流水完成业务说明、凭证留痕、主管审核、历史追溯和现金流统计。

当前版本不做正式会计凭证、税务、发票、借贷科目和自动表格导入。

## 二、角色和权限

管理员：

- 管理平台账号、租户系统、租用收费、统一分类、系统限制和服务器状态。
- 可开通租户系统，并设置首位主管账号。
- 可查看租户主管账号，并可重置租户账号密码和登录密钥。
- 可设置平台收款钱包、月租费用、首次开通优惠价和钱包启用数量上限。
- 可处理无法自动识别的租用付款和线下手工续费。
- 可查看、回复、处理和关闭全部租户工单。

主管：

- 管理本系统钱包、主管账号和员工账号。
- 审核批注、往来款和平账。
- 可将无业务用途的链上流水标记为非业务，也可恢复为待批注。
- 可提交租用续费交易哈希。
- 可提交工单、回复平台处理意见并关闭本系统工单。
- 可查看本系统业务相关日志和历史记录。

员工：

- 查看链上流水和账目记录。
- 对链上流水补充分类、业务说明和凭证图片。
- 可创建往来款、提交平账申请。
- 员工是否可查看全部账目由主管创建或维护账号时决定。

## 三、登录和账号安全

正式登录方式为登录账号、密码和可选登录密钥动态验证码。

- 登录页不再选择角色。
- 账号绑定登录密钥后，登录时必须输入 6 位动态验证码。
- 所有角色都可以在“我的账号”中修改自己的密码和重置自己的登录密钥。
- 管理员可维护平台和租户账号。
- 主管可维护本系统主管和员工账号。
- 生产环境不向前端公开账号列表，避免登录页暴露用户信息。

## 四、链上流水和钱包

当前链上同步优先支持 TRC20 USDT。

- 启用的钱包每 5 分钟自动同步一次。
- 钱包可手动立即同步。
- 钱包停用后会暂停自动同步和新增待办。
- 钱包重新启用后，会补同步停用期间的链上流水。
- 同一个系统内禁止重复添加同一个钱包地址。
- 新增钱包时可设置纳入管理时间，但只能选择 30 天内时间。
- 纳入管理时间用于判断历史流水是否需要批注，不影响链上流水本身保留。
- 已达到钱包启用数量上限时，不能新增或启用更多钱包。

## 五、流水批注和审核

业务批注基于真实链上流水，不再让员工手工填写金额和钱包。

- 金额、方向、钱包、交易哈希和链上时间来自链上。
- 批注时只需要选择分类、填写业务说明并上传凭证图片。
- 凭证只允许图片，支持点击上传和粘贴截图。
- 凭证会压缩保存，并通过权限接口预览或下载。
- 所有普通批注都需要主管审核。
- 已驳回批注可修改后重新提交。
- 已审核通过的普通批注可发起修正或冲正，所有版本保留历史；冲正通过后流水恢复待处理，可重新批注或平账。

非业务流水用于处理系统上线测试、归集、无业务关联等不应进入业务统计的链上流水。

## 六、往来款和平账

往来款是独立的应收款、应付款台账。

- 可创建应收款或应付款。
- 需要填写目标方、金额、分类和业务说明。
- 往来款需要主管审核。
- 平账从“流水账目”中选择链上流水发起。
- 一笔链上流水如果用于平账，必须整笔绑定，不能拆分，不能留余额。
- 一笔链上流水只能绑定一笔往来款；一笔往来款可以通过多笔链上流水分多次平账。
- 累计平账金额可以等于或略大于往来款金额，多出的部分记录为多收或多付。
- 平账也需要凭证和主管审核；平账通过后生成平应收款或平应付款业务记录，并计入业务收支统计。
- 已通过平账如有错误，可撤销平账；撤销后往来款金额回退，链上流水恢复待处理。
- 作废往来款和平账前会显示明细，避免误操作。

历史已经发生但未纳入系统的应付款，建议先补录应付款，再用对应历史链上出账流水整笔平账；如果该历史流水不需要批注，仍可作为历史平账依据保留追溯。

## 七、租用续费

当前租用续费采用交易哈希识别方案。

- 主管端可复制平台收款钱包。
- 租户付款后提交交易哈希。
- 系统按交易哈希排重，避免重复续费。
- 未开通租户可按首次开通优惠价自动开通 1 个月。
- 已开通租户按月租费用整数倍自动续费。
- 未能自动处理的付款进入管理员收入列表，由管理员人工处理。
- 管理员可按月、按天，或月数加天数组合手工续费。
- 到期租户会自动停用；续费成功后可自动恢复启用。

首次开通优惠价为 0 时，表示不开启首次优惠。首次优惠价应低于月租费用。

## 八、数据和日志

系统保留完整追溯链。

- 钱包、链上流水、批注、审核、修正、冲正、往来款、平账和租用付款都会保留历史。
- 工单用于主管和平台之间沟通续费、钱包、链上同步、账号和系统异常问题。
- 工单消息支持图片附件和粘贴截图，附件同样通过权限接口访问。
- 工单支持待平台回复、待租户回复、处理中和已关闭状态。
- 待租户回复超过 3 天会在列表提醒，第 4 天仍未回复会自动关闭，关闭后可通过回复自动重新打开。
- 已关闭工单仍可继续回复，提交回复后会自动重新打开并转为待对方回复。
- 管理员日志只在管理员后台审计。
- 主管端日志仅展示本系统业务相关记录。
- 自动同步成功且无新增流水时不记录普通操作日志，减少日志噪声。
- 流水账目默认查看最近 30 天。
- 操作日志默认查看最近 7 天。
- 关键列表支持筛选、分页和导出。

## 九、服务器和备份

生产环境信息：

- 生产域名：`https://acc.ziheexin.net`
- 服务目录：`/opt/usdt-ledger`
- 应用服务：`usdt-ledger.service`
- 数据库：PostgreSQL，仅监听服务器本机。
- 反向代理：Nginx + HTTPS。

服务器管理页可查看：

- CPU、内存、磁盘、运行时间。
- 数据库大小和连接情况。
- 附件数量和附件占用空间。
- 最近备份和备份 timer 状态。

备份 timer 当前用于备份：

- PostgreSQL 数据库 dump。
- 私有附件目录压缩包。
- sha256 校验清单。

正式上线后建议定期人工检查备份是否可用，并保留一份离线配置备份。`.env`、数据库密码、TRON API Key 和正式账号密码不得提交到 GitHub。

## 十、上线前确认项

正式上线前建议逐项确认：

- 正式管理员账号、密码和登录密钥已设置完成。
- 平台收款钱包地址已设置。
- 月租费用已设置。
- 首次开通优惠价已设置；如无活动则设置为 0。
- 每个租户的钱包启用数量上限已确认。
- TRON API Key 已配置在服务器环境变量中。
- 备份 timer 正常运行，并至少完成一次恢复演练。
- 是否清空当前测试数据已经最终确认。
- 主管和员工使用说明与当前功能一致。
- 手机端和 PC 端主要页面已人工复核。

## 十一、常见排查

链上同步显示未启用：

- 检查服务器是否配置 `TRON_API_KEY`。
- 检查当前系统是否已开通且未到期。
- 检查钱包是否启用。
- 手动刷新页面后等待自动状态更新。

租户无法新增或启用钱包：

- 检查租用状态是否为已开通且未到期。
- 检查钱包启用数量是否达到上限。
- 检查钱包地址是否已在本系统添加过。
- 检查纳入管理时间是否超过允许范围。

续费哈希未自动生效：

- 检查交易是否真实到达平台收款钱包。
- 检查交易哈希是否已经提交过。
- 检查付款金额是否符合当前自动续费规则。
- 无法自动处理时，由管理员在收入列表中人工处理。

业务数据看不到：

- 检查当前登录账号所属系统。
- 检查员工是否被限制为只能看自己提交的账目。
- 检查页面默认时间范围和筛选条件。
- 检查租户是否已停用或到期。

需要平台协助排查：

- 主管优先在工单中心提交问题。
- 工单内容建议包含发生时间、页面名称、钱包地址、交易哈希和已尝试操作。
- 平台回复后，主管根据工单状态补充信息或关闭工单。

新版本未显示：

- 系统前端有版本更新提示时，点击刷新。
- 如果浏览器缓存仍旧显示旧版，可手动刷新当前页面。
